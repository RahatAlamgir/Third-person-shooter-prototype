# Third-person-shooter-prototype
Third person shooter prototype made with Unity


## Features
- Third-person character movement (extended starter asset)
- Cinemachine camera
- Shooting system
- Basic object interaction
- UI elements
- DOTween for (door/chest animation , moving object)

## Tools
- Unity
- C#
- Cinemachine
- DOTween
- Starter Assets
